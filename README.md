# EpiBot-Colombia-
Una página web que lee cada día noticias regionales y boletines oficiales, usa IA para detectar los focos de dengue municipio por municipio, e indica si cada señal es una noticia no confirmada o está respaldada por fuentes oficiales.

# MVP
- Dos o tres fuentes reales conectadas.
- La IA que lee y resume
- Niveles de alerta simples.
- Las cuatro pantallas del diseño: 
Panel general, con las alertas activas.
Búsqueda y mapa, por patógeno o departamento. Es el corazón de la demo.
Detalle de alerta, con el resumen de la IA, la línea de tiempo y las fuentes.
Fuentes de información, que muestra de dónde viene cada dato. Le da credibilidad.
- Pocos patógenos.
- Datos precargados
